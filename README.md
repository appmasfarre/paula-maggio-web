# Paula Maggio · Comunicación & eventos

Landing estática de paulamaggio.com.ar. No usa framework ni paso de build: `index.html` contiene el HTML, el CSS y el JS; `img/` guarda las fotos optimizadas (webp) y los recursos de marca, y `fonts/` la tipografía Ivy Presto Headline.

Se publica en Vercel con cada push a `main`.
